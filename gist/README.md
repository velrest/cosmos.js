# cosmos.js demo

A self-contained demo of cosmos.js, a data framework where the real sky controls what you can read. Gists don't serve pages themselves, so open `index.html` through a gist viewer such as [githack](https://raw.githack.com/).

**GitHub page:** https://velrest.github.io/cosmos.js/

Star data comes from the [HYG Database](https://github.com/astronexus/HYG-Database), CC BY-SA 4.0. Land outlines come from [Natural Earth](https://www.naturalearthdata.com/), public domain.
